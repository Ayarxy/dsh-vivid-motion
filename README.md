# dsh-vivid-motion

DSH Web 界面动效聚合包。四个组件可在 Plugin Manager 中分别启停，停用后卸载对应效果。

| 组件 | 功能 |
| --- | --- |
| dsh-click-spark | 放射状点击粒子，300 ms 结束，颜色跟随主题 |
| dsh-copy-toast | 复制或剪切后显示确认提示，最多堆叠 4 枚，停留 2000 ms |
| dsh-smooth-caret | 平滑光标与彗星拖尾，可设置颜色、粗细和独立闪烁 |
| dsh-reasoning-slider | 模型与推理强度滑块；拖动预览、松手提交，最高档显示紫色流动与粒子 |

## 安装

先在本目录安装依赖：

```bash
npm install
```

再任选一种方式安装：

- 命令行：`dsh plugin --profile desktop add link:<本目录绝对路径>`。
- Desktop 应用：「设置 → 插件 → 添加插件」，填入本目录绝对路径，安装后点击「立即启用」。

启用后刷新界面。

## 使用

### 复制提示

悬停提示可暂停倒计时，按住左右拖动超过 64 px 可丢弃。提示与宿主复制按钮的「已复制」反馈同时出现；关闭此组件可仅保留宿主反馈。宿主没有剪切确认。

仅在写入成功且载荷非空时提示；剪切还要求选区可编辑、原文确实被删除，包括换行或段落结构的删除。空载荷、只读或禁用控件上的剪切、脚本合成事件均不提示。同一次同步调用中的嵌套写入只提示一次，连续复制分别提示；停用后不补发提示，提示异常不影响原复制结果。

### 平滑光标

在「设置 → Vivid Motion → dsh-smooth-caret」调整移动、拖尾、闪烁及 1 / 2 / 3 px 粗细。颜色可选「跟随主题 / 蓝色 / 萨尔萨红 / 自定义」，萨尔萨红为 `#FD3A4A`；自定义色支持拖动、键盘及 `#RRGGBB` 输入，点击「应用」保存，取消保留原色。

默认启用平滑移动与拖尾，闪烁关闭；开启后亮、灭各 500 ms。设置保存在本浏览器并立即生效，存储受限时仍可在当前页面使用。

支持横排聊天编辑器与询问作答框，跟随选区活动端、滚动和组合输入，不改动正文、焦点或选区。失焦、页面隐藏、停用、强制颜色模式或定位不可靠时恢复原生光标。普通设置输入框、只读或禁用字段、不可编辑内容、竖排编辑器、原生 dialog 内的输入、iframe、任意旋转变换及自定义编辑器布局不在支持范围内。

此组件仅参考 [smooth-cursor](https://github.com/Lacquervii/smooth-cursor) 及 [Issue #1](https://github.com/Lacquervii/smooth-cursor/issues/1) 的功能描述，未引入源码或资源。

### 模型与推理强度

输入栏保持「模型名 + 推理强度」。弹窗默认在按钮上方居中，空间不足时避让边缘；切换面板时连续展开或收起。最高档效果随当前模型公布的档位变化，不固定绑定 `ultra`，切回其他档位或提交失败时同步恢复颜色。

支持键盘和滚轮选择。等待提交期间仍可调整同一模型的档位，后续仅按顺序提交最新待发选择；中间回执不覆盖最新位置，失败时显示原错误并回到宿主确认的值。停用、锁定或切换会话后丢弃旧队列。

等待期间可查看模型列表，但不能切换模型或在搜索框中按 Enter 选择模型；Escape / Tab 仍可退出。插件不缩短宿主模型选择请求的耗时。

## 已知限制

- 开启「减少动态效果」后，点击粒子不触发，复制提示动画缩至 1 ms，光标恢复原生，滑块关闭过渡、缩放与粒子，WebGL 仅绘制静态帧。
- 剪贴板 DOM 事件没有系统回执，iframe 内复制、无可读选区的默认复制可能漏报。未知自定义 `toString`、非标准数组迭代或元素访问器的载荷不确认；缺少原生 `ClipboardItem` 检查接口时，`write()` 不提示。绕过包装直接调用原生 DataTransfer 方法时，载荷变化无法可靠判定；第三方异步另行执行复制可能出现双提示。
- 当前版本尚未复测 DSH 实际界面、GPU 或滚动几何，也未确认宿主已加载此版本；真实输入法候选窗仍需在 DSH 中确认。离线检查不能替代这些验证。

开发与验证约定见 [AGENTS.md](AGENTS.md)。
